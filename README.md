# WiselyDeliv

骑手辅助工具，Android。这里只放安装包，源码不在这个仓库。

## 下载安装

1. 到 [Releases](../../releases/latest) 下载 `app-release.apk`
2. 点开下载好的文件 → 会弹出「不允许安装未知来源应用」→ 弹窗上有「设置」按钮，
   点进去把开关打开 → 返回 → 安装。**这一步只需要做一次**，以后更新不会再问。
3. 装完打开 app，首页会按顺序告诉你还差哪几步，跟着点就行（一共三步）。

### 第 2、3 步的开关是灰的、点不动？

Android 13 以上的手机，从应用商店以外装的 app 默认不让开这两个权限。首页那一步
底下有一个「打开 Deliv 的应用信息页」按钮，点它 → 右上角 ⋮ →「允许受限设置」，
然后返回重来一次就能开了。

## 更新

有新版本时 app 首页顶上会出现一个下载按钮，点它下载新的安装包，装上去覆盖旧的
就行——订单记录和设置都会保留。
